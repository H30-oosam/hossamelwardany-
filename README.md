# Hossam Elwardany Professional Website

نسخة أولى قابلة للتشغيل فوراً بدون Node أو Supabase.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو استخدم أي static server.

## الصفحات
- `index.html` الرئيسية
- `about.html` من نحن
- `services.html` الخدمات
- `projects.html` المشروعات
- `articles.html` المقالات
- `article.html` نموذج مقال
- `contact.html` التواصل
- `admin.html` لوحة إدارة محلية تجريبية

## CMS
الـAdmin الحالي يستخدم `localStorage` حتى تعمل النسخة فوراً بدون Backend.
يمكن إضافة/نشر/إخفاء/حذف المقالات محلياً.

## GitHub Pages
1. ارفع جميع الملفات كما هي إلى Repository على GitHub.
2. من Settings > Pages اختر Deploy from a branch ثم main / root.
3. افتح رابط الموقع بعد اكتمال النشر.
4. لوحة الإدارة: `admin.html`
5. كلمة مرور لوحة الإدارة الحالية: `1321994`

### تنبيه أمني مهم
هذه النسخة تعمل كـ Static Website، لذلك كلمة المرور الموجودة في JavaScript ليست حماية أمنية حقيقية ضد شخص لديه وصول إلى ملفات الموقع. هي مناسبة لمنع الدخول العرضي إلى صفحة الإدارة فقط. إذا كان الموقع سيستخدم فعليًا لإدارة مقالات ورسائل وبيانات عملاء، يجب نقل تسجيل الدخول والإدارة إلى Backend مثل Supabase Auth + RLS أو نظام خادم حقيقي.
